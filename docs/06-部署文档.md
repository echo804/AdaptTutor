# 部署文档（M4，本地一键启动 + 端口说明）

## 一键启动（docker compose）

```bash
docker compose -f docker-compose.local.yml up -d --build
```

启动三个服务：
| 服务 | 容器 | 端口 | 说明 |
|---|---|---|---|
| postgres | adapttutor-postgres | 5433（宿主）/5432（容器内） | PG 16，数据卷 pgdata |
| api | adapttutor-api | 8010 | FastAPI + uvicorn（8000 被上级项目占用，固定 8010） |
| web | adapttutor-web | 3000 | Next.js dev（node:20-alpine） |

> 端口约定：8000/5432 被上级项目占用，本项目统一 8000→8010、5432→5433。

## 本地开发启动（不经 docker）

```powershell
# 1. PG（已由 compose 提供，或单独起）
docker compose -f docker-compose.local.yml up -d postgres

# 2. 后端（backend/ 目录，.venv）
.venv\Scripts\python.exe -m alembic upgrade head        # 首次：建表/迁移
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010

# 3. 前端（frontend/ 目录，node 20）
npm run dev -- -H 127.0.0.1                              # http://localhost:3000
```

## 首次使用流程

1. **生成邀请码**（backend/ 目录）：
   ```powershell
   .venv\Scripts\python.exe scripts/gen_invite.py --count 1 --days 7
   ```
2. 打开 http://localhost:3000 → 邀请码注册
3. 设置页配置 LLM API key（DeepSeek/Qwen/GLM，仅掩码存储）
4. 对话页开始诊断/辅导

## 健康检查

- `GET http://localhost:8010/healthz` → `{"ok": true, "db": "up"}`（应用存活 + PG 连通）

## 每日备份

```powershell
.venv\Scripts\python.exe scripts/backup.py --keep 7   # pg_dump → D:\AdaptTutorBackup
```

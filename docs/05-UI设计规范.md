# 05-UI 设计规范

> 设计理念与视觉规范（2026-08 确认）。本文档是前端实现（Next.js + TailwindCSS + @xyflow/react + KaTeX）的"图纸"。

---

## 1. 设计理念：一个"思考的房间"

> 干净、安静、没有多余的元素，但有一束温暖的光照在你要思考的问题上。

三条推论（贯穿所有页面）：
1. **色彩的唯一作用是指引注意力**——只有当前追问、正在查看的知识节点、需要学生点击的交互元素，才使用强调色；其余一切保持中性。
2. **动效只用于两种目的**——引导注意力（如新消息出现）或解释信息变化（如路径动画展示因果关系）；任何纯装饰性动效都是多余的。
3. **界面为"长时间思考"服务**——字号、行高、对比度都按护眼标准设计，不讨好眼球。

## 2. 配色系统

### 2.1 双主题（跟随系统，Tailwind `darkMode: 'media'`）

| 角色 | 浅色模式 | 暗色模式 |
|---|---|---|
| 背景 | 柔和米白 `#FAFAF9` | 深灰 `#1E1E1E` |
| 正文 | 深灰 `#1A1A1A` | 暖白 `#E8E6E3` |
| 主强调色 | 墨蓝 `#2C3E50`（克制、安静） | 琥珀 `#D4A574`（一束温暖的光） |

> 备注：暗色主强调原方案"琥珀 `#D4A574` 或薄荷绿 `#7EC8A0`"——**默认琥珀色**（呼应"温暖的光"隐喻）；薄荷绿 `#7EC8A0` 划归"掌握/成功"语义色（见 2.3），不与主强调混用。

### 2.2 强调色使用纪律（核心规则）

强调色只允许出现在三种位置：
1. **当前正在进行的追问**（对话中需要认真对待的思考点）；
2. **正在查看/被选中的知识节点**（图谱、报告中的当前焦点）；
3. **需要学生点击的交互元素**（按钮、作答入口）。

除此之外一律中性色。宁少勿多。

### 2.3 语义色

| 语义 | 颜色 | 用途 |
|---|---|---|
| 掌握度色阶 | 冷灰 `#94A3B8` → 暖绿渐变（终 `#7EC8A0`） | 图谱节点填充（见 5.2） |
| 正确反馈 | 绿（与掌握绿同系） | 判题对勾、肯定语 |
| 错误反馈 | 红（克制，低饱和） | 判题错误提示，仅作状态不作装饰 |
| 溯源路径 | 暖色发光（琥珀系） | 图谱溯源路径动画（见 5.2） |

### 2.4 中性层级（浅色示例，暗色对称）

- 卡片：白底（暗色：`#262626` 级）、圆角 8-12px、轻阴影
- 页面背景：`#FAFAF9`
- 次级文字：灰（浅色约 `#6B7280`）
- 分隔线：极浅灰

## 3. 字体系统

| 场景 | 字体 | 规格 |
|---|---|---|
| 对话内容 | 系统默认中文字体 | 16-18px，行高 1.8 |
| 数学公式 | KaTeX | 与正文风格统一 |
| 图谱标签 | 等宽/半等宽字体 | 强调"结构化""精确性" |

字体栈（Windows + macOS 兼容）：
```css
--font-ui: -apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", system-ui, sans-serif;
--font-mono: ui-monospace, SFMono-Regular, Consolas, "Courier New", monospace;
```
图谱标签用 `--font-mono`；其余全部 `--font-ui`。

## 4. 布局框架

### 4.1 主布局：顶栏 + 侧边栏（双层）

```
┌─────────────────────────────────────────────┐
│ Logo │ 会话类型入口 │ [当前学生▾] ⚙ 退出     │ ← 顶栏（全局常驻）
├──────────┬──────────────────────────────────┤
│ 侧边栏    │                                  │
│ · 仪表盘  │         内容区                    │
│ · 图谱    │                                  │
│ · 报告    │                                  │
│ · 设置    │                                  │
│ · 编辑器* │                                  │
└──────────┴──────────────────────────────────┘
```
- 顶栏：品牌 + 会话快捷入口（诊断/辅导/复习）+ 学生切换 + 账号。
- 侧边栏：页面导航（*编辑器 M2/M3 后启用时加入）。
- 侧边栏可折叠（窄屏/平板收为抽屉）。

### 4.2 会话页布局：左右分栏（独立全屏，无顶栏/侧边栏）

```
┌──────────────────────────┬──────────────────┐
│  对话流（主区域，左）      │ 右栏（可折叠/隐藏） │
│  · 状态指示器（顶部）      │ · 当前题目卡片     │
│  · 学生气泡（右对齐）      │ · 图谱局部视图     │
│  · AI 气泡（左对齐）       │ · 会话进度         │
│  · 追问高亮 + 细竖线       │                  │
│  · 草稿区（输入框上方）    │                  │
├──────────────────────────┴──────────────────┤
│  输入区：作答切换（选/填/解）+ 文本发送         │
└─────────────────────────────────────────────┘
```
会话页独立全屏：防误触导航，学生只面对对话（对齐"会话零干扰"原则）。

## 5. 页面视觉语言

### 5.1 苏格拉底对话界面（核心页面）

- **气泡**：AI 左对齐、学生右对齐。AI 气泡**不用任何鲜艳颜色**——浅灰背景 + 深灰文字（暗色模式对称反转），保持极简。
- **追问高亮**：AI 提出关键追问时，文字用主强调色，左侧加**细竖线标记**——暗示"这是一个需要认真对待的思考点"。竖线是追问的专属视觉符号，不可挪用。
- **草稿区（思考区）**：学生输入框上方，可折叠，设计成**便签纸**质感；鼓励先写思路再提交回答。草稿在提交后可保留/清空。
- **状态指示器**：对话顶部极简进度条或圆点组，显示当前处于"探明 → 识别错误 → 最小提示 → 变式验证"（03 文档四态）哪个阶段。**半透明设计，不抢夺注意力**。
- **作答组件随题型切换**：选择题→选项按钮组；填空题→单行输入 + 判题反馈；解答题→多行文本 + 发送。

### 5.2 知识图谱页面（诊断与溯源）

- **画布**：图谱区域**始终使用深色背景**（即使浅色模式下）——深色背景让彩色节点和边的关系更突出。这是有意为之的对比设计。
- **节点**：简洁圆形或圆角矩形。**掌握度用填充比例表示**——空心（未学）、半满（薄弱）、实心（掌握）；颜色冷灰到暖绿渐变（`#94A3B8` → `#7EC8A0`）。
- **溯源路径**：展示错题溯源时，一条**发光的暖色路径**从"错误知识点"沿依赖边向上追溯，停在"根因知识点"；根因节点有**呼吸般的脉冲动画**。
- **交互**：可拖拽、缩放；点击节点展开——简短说明、掌握度详情、快捷操作（开始学习 / 做道题试试）。

### 5.3 诊断报告页面

- **定位**：像一份结构清晰的分析报告，**不是花哨的仪表盘**。
- 顶部：**一句话总结**，大号文字。例："你的核心薄弱点在因式分解，这影响了你在一元二次方程上的表现。"
- 中部：知识图谱缩略视图，溯源路径高亮。
- 下部：可操作推荐路径——卡片列表，每张卡片对应一个学习步骤，含**预估时间 + 难度标识**。

### 5.4 仪表盘 / 设置 / 登录

- **仪表盘**：今日推荐（到期复习数 + 建议动作）→ 掌握度总览 → 最近会话 → 学习趋势。与报告页共用"数据中立呈现"原则，不堆装饰。
- **设置页**：学生管理（增删/切换/重新诊断入口）、账号（改密码）、领域包列表（激活切换）。
- **登录页**：居中卡片，用户名/密码/登录，无装饰；暗色模式自动切换。

## 6. 动效原则

**极度克制**。禁用：弹跳、旋转、缩放弹入等装饰性动画。

唯一允许的三种动效：

| 动效 | 实现 | 用途 |
|---|---|---|
| 淡入淡出（Fade） | CSS opacity transition | 内容出现/消失（新消息等） |
| 路径绘制 | SVG `stroke-dashoffset` | 图谱溯源路径展示（因果关系） |
| 脉冲（Pulse） | CSS keyframes | 提醒回答追问 / 标记刚更新的节点状态 |

不引入动画库（framer-motion 等），CSS 足够——遵循"能砍则砍"。

## 7. 空状态与情感化细节

| 场景 | 设计 |
|---|---|
| 首次进入 | 不冰冷空白。引导语："准备好开始诊断测试了吗？我会用几道题找到你最需要帮助的地方。" + 简洁的知识图谱生长动画 |
| 回答正确 | 无撒花/夸张庆祝。简单对勾动画 + 中性真诚肯定（"很好，你的思路是对的。"）；更好的做法是追问一句："你能否用另一种方法再验证一下？" |
| 卡住时 | 检测到连续出错或长时间停留，对话顶部浮现轻量提示："感觉有点难？试试把问题拆成更小的部分。" |
| 完成学习单元 | 图谱对应节点黄→绿，伴随一次安静的填充动画；整个图谱短暂闪烁一下，像一颗星星被点亮 |

情感化细节全部服务于"引导思考"本身，不制造噪音。

## 8. 技术实现要点

- **Tailwind**：`darkMode: 'media'`（跟随系统，默认行为）；扩展色板 `stone`（米白/深灰系）+ 自定义 `accent`（浅色墨蓝 / 暗色琥珀）+ 掌握度色阶。
- **React Flow（@xyflow/react v12）**：自定义节点（填充比例表示掌握度）、自定义边（溯源路径发光 + stroke 动画）、画布强制深色；`dynamic(..., { ssr: false })` 导入规避 SSR 报错。
- **KaTeX**：对话与题干公式渲染，与正文风格统一。
- **草稿区**：可折叠便签样式组件，状态存前端（会话中断不丢失为佳，可后置到本地存储）。
- **状态指示器**：由状态机当前状态驱动（探明→识别错误→最小提示→变式验证），半透明圆点组。
- **字体**：CSS 变量 `--font-ui` / `--font-mono`，Tailwind `fontFamily` 扩展。

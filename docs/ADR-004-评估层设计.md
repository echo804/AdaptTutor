# ADR-004：引导纯度评估层（自检规则 + 回归测试集 + 拒答检测）

> 状态：**已接受（2026-08）** · 关联：docs/02 §3.1、docs/03 §4、F2 冻结点

## 背景

核心硬约束是"苏格拉底式引导：不直接给答案"（04 决策）。需要**可测量、可验证**地保证引导纯度（目标 ≥ 90%），不能只靠模型自觉。

## 决策

三层防线（`engine/state_machine/`）：

1. **输出自检层 `output_sanitizer.py`**（机器防线）：
   - 规则检测：最终答案句式（"答案是/最终答案/结果等于"）、完整解题步骤（连续步骤序列"第一步…第二步"、解:+多行）、选项字母泄露（choice 题正文出现 A/B/C/D）
   - 命中 → 触发重生成（最多 N 次，编排层注入 LLMJudge 双判定）
   - 仍泄露 → **降级为更模糊提示**（`degraded=True`），宁可模糊不给答案

2. **拒答检测 `refusal_detector.py`**：识别 AI 拒绝回答/绕开问题的场景，触发重试或降级

3. **回归测试集**（`scripts/eval_prompts.py` + 20 题引导语回归集）：每次变更后自动跑，用真实 LLM 验证纯度；F2 实测 **20/20 = 100%**

## 为什么

1. **可测量**：纯度是量化硬指标（02 §3.1），回归集提供测量手段
2. **双保险**：规则自检（确定性强）+ 轻量模型双判定（语义兜底）互补
3. **降级优先于泄露**：不确定就模糊，守住"不给答案"底线
4. **数据沉淀**：评估结果存 PG，未来可作微调语料（04 后置项）

## 后果

- 正面：纯度 100% 达成（F2）、防回归（每次变更自动跑）
- 代价：自检规则需随语言/题型演进维护（如"第一步"单用是引导语不算泄露的边界处理）
- 演进：规则库可扩展新题型/新泄露模式，回归集可增补场景

## 验证

- 引导纯度回归集 20 题 100%（F2 冻结点）
- 状态转移矩阵单测全绿（F2）
- 架构检查单"状态机四态转移矩阵有单测" ✓

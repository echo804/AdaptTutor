## 2. 引擎与领域包边界

### 2.1 引擎（领域无关，核心代码）

| 模块 | 职责 | 关键接口 |
|---|---|---|
| `state_machine` | 苏格拉底四态流转、非法跳转拒绝、挫败感检测 | `TransitionResult step(session, user_msg)` |
| `diagnostic` | KST 自适应选题、BKT 掌握度更新 | `select_next_question(mastery)` / `update_mastery(evt)` |
| `graph_engine` | 路径规划（拓扑+权重）、错题溯源（依赖链回溯） | `plan_path(weak_nodes)` / `trace_root(wrong_node)` |
| `scheduler` | 遗忘曲线复习时间窗、变式题触发 | `due_reviews(student)` / `schedule_next(lesson)` |
| `evaluator` | 引导纯度检测、回归测试集执行 | `purity_score(message)` / `run_regression(suite)` |
| `llm_gateway` | LiteLLM 封装、分层路由、故障转移 | `generate(role, prompt, ctx)` |
| `domain_pack` | 领域包 schema 校验、运行时导入 | `load(pack_id)` / `validate(manifest)` |
| `persistence` | PG 访问层（repository 模式，可替换） | 各实体 CRUD |

### 2.2 领域包（数据 + 配置，可插拔）

```
domain_packs/初中数学_方程与不等式/
├── pack_manifest.json        # id、版本、学科、依赖引擎版本
├── knowledge_graph.json      # 节点[难度/重要度/错误模式] + 有向边[前置依赖]
├── questions.json            # 题干/知识点标签/难度/选项错误模式/步骤→节点映射
├── diagnostic_rules.json     # 初始选题策略、终止条件、BKT 参数
├── assessment_config.json    # 引导纯度规则、掌握度阈值、回归测试集引用
└── curriculum_meta.json      # 教材/考纲映射（供 LLM 半自动建图校验）
```

**接入新领域 = 新增一个目录，零改引擎代码**（引擎只认接口不认内容）。

## 3. 数据模型（PG 核心表）

| 表 | 关键字段 | 职责 |
|---|---|---|
| users | id, username, password_hash, created_at, meta | 账号 + 学生档案（**用户即学习者**，student_id = user_id） |
| user_api_keys | user_id, provider, encrypted_key, created_at, updated_at | 用户自配 LLM key（Fernet 加密存储，见 04 2.9） |
| invite_codes | code, used_by, created_at, expires_at, used_at | 邀请码注册（CLI 脚本生成） |
| sessions | id, student_id(=users.id), type(诊断/辅导/复习), status, started_at, ended_at | 会话（任务状态持久化于此，重启可恢复） |
| messages | id, session_id, trace_id, role, content, purity_score, created_at | 每轮消息（含评估分） |
| mastery_states | student_id(=users.id), node_id, mastery_p, confidence, last_review_at, decay_state | 掌握度（BKT 概率） |
| learning_events | id, student_id(=users.id), session_id, event_type, node_id, payload, ts | 事件流（评估/回溯唯一依据） |
| evaluations | id, session_id, eval_type, result, detail, ts | 诊断结果/溯源路径/纯度评分 |
| question_bank | id, domain_pack, content, tags, difficulty, error_modes, step_node_map, embedding(预留) | 题库 |
| knowledge_graph | id, domain_pack, graph_jsonb, version | 图谱 |

> **用户即学习者**（04 决策）：无独立 students 表，sessions/mastery_states/learning_events 的 `student_id` 即 `users.id`；用户数据天然按 user 隔离。

**图谱 JSONB 结构**（节点 ≤ 500 规模）：
```json
{
  "nodes": [{"id": "k01", "name": "一元一次方程", "difficulty": 0.6,
             "importance": 0.9, "error_modes": ["移项符号错误", "系数化简错误"]}],
  "edges": [{"from": "k01", "to": "k02", "type": "prerequisite"}]
}
```

**索引**：users(username) 唯一；user_api_keys(user_id, provider) 唯一；invite_codes(code) 唯一；mastery_states(student_id, node_id) 唯一；learning_events(student_id, ts)；messages(session_id, trace_id)。

## 4. 苏格拉底状态机（四态）

```
        ┌─────────┐  学生回答   ┌─────────┐
        │ 探明卡点  │ ────────→ │ 识别错误  │
        └────┬────┘           └────┬────┘
             │ 已定位               │ 已分类
             ▼                     ▼
        ┌─────────┐  提示后     ┌─────────┐
        │ 最小提示  │ ────────→ │ 变式验证 │
        └────┬────┘           └────┬────┘
             │ 学生答对             │ 验证通过
             └─────────────────────┴──→ 完成/下一题
```

- **状态持久化**：状态存于 sessions.status + 上下文，重启可恢复。
- **非法跳转**：状态转移矩阵硬约束，单元测试全覆盖（如"未探明卡点不得直接给提示"）。
- **输出自检层**：LLM 生成内容先过规则（禁止最终答案句式/完整解题步骤）+ 轻量模型双重判定，泄露则重生成（最多 2 次，仍泄露则降级为更模糊的提示）。
- **挫败感检测**：连续错误 ≥3 或回复长度骤降或负面情绪词 → 降提示层级 / 切换讲解模式。

## 5. API 设计（草案）

### 5.0 认证与设置（对齐 04 v0.3/v0.4）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/login` | 登录（用户名 + 密码 → JWT） |
| POST | `/auth/register` | 注册（用户名 + 密码 + 邀请码 `invite_code`） |
| GET | `/auth/me` | 当前用户信息 |
| GET | `/me/api-keys` | 已配置 key 的供应商列表（仅掩码，不可回读明文） |
| PUT | `/me/api-keys/{provider}` | 配置/更新某供应商 key（保存时可选测试调用验证） |
| DELETE | `/me/api-keys/{provider}` | 删除某供应商 key |

> **鉴权**：除 `/auth/login`、`/auth/register`、`/healthz` 外，全部接口需 `Authorization: Bearer <JWT>`；业务数据均限当前登录用户（student_id = user_id），越权访问直接 403。
> **key 门槛**：用户必须配置有效 key 才能使用 AI 功能（诊断/辅导/复习/判题）；未配 key 仅可浏览，AI 入口由前端置灰并引导（04 2.9）。

### 5.1 会话与辅导

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/sessions` | 创建会话（type: diagnostic|tutor|review） |
| POST | `/api/v1/sessions/{id}/messages` | 发送消息，返回状态机下一步（WebSocket 流式） |
| GET | `/api/v1/sessions/{id}` | 会话详情（含状态机当前状态） |
| GET | `/api/v1/sessions/{id}/messages` | 消息历史（按 trace_id 可回溯） |

### 5.2 诊断与图谱

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/diagnostics/{session_id}/answer` | 提交诊断题答案，返回下一题与收敛进度 |
| GET | `/api/v1/students/{id}/mastery` | 掌握度快照（图谱节点概率） |
| GET | `/api/v1/students/{id}/path` | 当前推荐学习路径 |
| GET | `/api/v1/students/{id}/trace/{node_id}` | 错题溯源路径（表面错题→根因） |

> 鉴权注：`/api/v1/students/{id}/*` 中的 `{id}` 必须等于当前登录用户的 user_id（用户即学习者），访问他人数据返回 403。

### 5.3 评估与运维

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/evaluations/{session_id}/purity` | 会话引导纯度评分 |
| POST | `/api/v1/regression/run` | 手动触发回归测试集 |
| GET | `/healthz` | 健康检查（含 PG 连通 + 领域包加载状态） |

### 5.4 协议约定
- 消息统一带 `trace_id`（贯穿 messages/learning_events/evaluations/日志）。
- 流式对话用 WebSocket；非实时操作用 REST + FastAPI BackgroundTasks（任务状态查 sessions.status）。

## 6. 目录结构（代码蓝图）

```
AdaptTutor/
├── domain_packs/                 # 领域包（数据）
│   └── junior_math_eq_ineq/
├── backend/
│   ├── app/
│   │   ├── main.py               # FastAPI 入口 + 路由
│   │   ├── config.py             # pydantic-settings 配置 + fast fail 校验
│   │   ├── auth/                 # JWT 认证 + 邀请码注册（04 5.0）
│   │   ├── keys/                 # 用户 API key 管理（Fernet 加密，04 2.9）
│   │   ├── engine/               # 引擎层（领域无关）
│   │   │   ├── state_machine/
│   │   │   ├── diagnostic/
│   │   │   ├── graph_engine/
│   │   │   ├── scheduler/
│   │   │   ├── evaluator/
│   │   │   └── llm_gateway/      # LiteLLM 封装 + 按用户 key 路由
│   │   ├── domain/               # 领域包加载器
│   │   ├── persistence/          # PG repository（可替换接口）
│   │   └── api/                  # 路由 + schema
│   ├── migrations/               # Alembic
│   └── tests/                    # 单元/集成/回归/故障注入
├── frontend/                     # Next.js（登录/对话/图谱/报告/仪表盘/设置/编辑器）
├── scripts/                      # 备份/发布/联调/邀请码生成（gen_invite.py）
├── docker-compose.local.yml      # 本地开发栈（本期实现）
├── docker-compose.prod.yml       # 生产栈（上云前置：nginx/HTTPS/卷策略，本期不实现）
├── .env.example
└── docs/                         # 本目录文档 + ADR
```

**架构纪律**：引擎模块不 import FastAPI/SQLAlchemy 具体实现（依赖反转）；persistence 用 repository 模式，保证图谱存储可替换（PG JSONB ↔ 未来图数据库）。

## 7. 架构验收检查单

- [x] 引擎模块无框架耦合（可脱离 FastAPI 单测）
- [x] 图谱/题库数据全部来自领域包，无硬编码
- [ ] 所有模块读同一 PG 状态（无模块内私有状态漂移）
- [x] 状态机四态转移矩阵有单测
- [ ] trace_id 贯穿消息/事件/评估/日志
- [x] 会话状态可持久化恢复（重启不丢）
- [ ] 图谱存储可替换（repository 接口）
- [ ] 认证与会话隔离：除 login/register/healthz 外均需 JWT；业务数据限当前用户（越权 403）
- [ ] 用户 API key Fernet 加密存储，界面仅掩码显示、不可回读
- [ ] 未配 key 用户不可触发 AI 功能（前端置灰 + 后端 403 双保险）
- [ ] 邀请码注册可用（CLI 生成、一次性、过期失效）
